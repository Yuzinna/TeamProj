# 기능 명세서: 다이얼로그 시스템

**기능 브랜치**: `001-dialogue-system`
**생성일**: 2025년 11월 11일
**상태**: 초안
**입력**: 사용자 설명: "게임 전체에서 사용할 UI 기반의 Dialogue 시스템을 생성한다. 이 기능의 목표는 NPC와의 상호작용 및 스토리 진행을 위한 것이다. 다이얼로그는 화면 하단 중앙에 고정된 크기로 나타나야 하며, 텍스트는 타이핑 효과(Typewriter Effect)로 점진적으로 출력되어야 한다. 플레이어가 'Enter' 키를 누르면 타이핑이 즉시 완료되거나 다음 대화로 넘어간다. 대화 데이터는 외부 JSON 파일에서 로드하여 순서대로 표시되어야 한다. 다이얼로그가 활성화되면 게임 시간(Time.timeScale)은 정지되어야 한다."

## 명확화된 내용

### 세션 2025-11-11
- Q: 대화 데이터 파일(JSON)을 로드하는 데 실패했을 때 시스템이 어떻게 동작해야 합니까? → A: 대화 기능을 비활성화하고, 콘솔에 에러 로그를 기록합니다.
- Q: 한 번에 표시할 대화 내용이 대화창의 공간을 초과할 경우 어떻게 처리해야 합니까? → A: 대화창 너비에 맞춰 텍스트를 자동으로 줄바꿈합니다.
- Q: 대화가 활성화된 동안 'Enter' 키를 제외한 플레이어의 다른 모든 입력(이동, 액션 등)을 어떻게 처리해야 합니까? → A: 입력을 enter말고 space로 바꾸고 다른 입력은 무시 하기
- Q: `Dialogue` 엔티티에 화자 이름, 초상화 이미지 경로와 같은 추가 정보를 포함해야 합니까? → A: 화자 이름(string)을 `Dialogue` 엔티티에 포함합니다.
- Q: 플레이어가 NPC와 상호작용하여 대화를 시작하는 구체적인 메커니즘은 무엇입니까? → A: 우리 게임에서 승객이 자동으로 데스크에 오는데 오면 자동으로 대화가 시작될거야
- Q: 대화 도중 씬(Scene) 전환이 시도되거나 게임이 종료될 때, 대화 상태(예: `Time.timeScale`)를 어떻게 처리해야 합니까? → A: 씬 전환 시 `OnDestroy` 등에서 `Time.timeScale`을 정상 복원합니다. (강제 종료는 OS가 처리)

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 기본 대화 출력 (우선순위: P1)

승객(NPC)이 데스크에 도착하면 대화창이 자동으로 나타나고 텍스트가 타자기 효과로 출력된다. 이 때 게임 내 시간은 멈춘다.

**우선순위 이유**: 대화 시스템의 가장 핵심적인 기능으로, 사용자에게 스토리를 전달하는 첫 단계이다.

**독립 테스트**: 승객이 데스크에 도착했을 때, 대화창이 정상적으로 표시되고 타자기 효과와 함께 텍스트가 나타나는지 확인한다. 게임 배경이 완전히 정지되었는지 확인하여 독립적으로 테스트할 수 있다.

**인수 시나리오**:

1. **Given** 승객이 데스크에 도착하고 게임 시간이 흐르고 있을 때, **When** 승객이 데스크에 도착하면, **Then** 화면 하단 중앙에 대화창이 나타나고 게임 시간(Time.timeScale)은 0이 된다.
2. **Given** 대화창이 열렸을 때, **When** 대화 내용이 출력될 차례가 되면, **Then** 텍스트가 한 글자씩 순차적으로 나타나는 타자기 효과가 재생된다.

---

### 사용자 스토리 2 - 대화 넘기기 및 스킵 (우선순위: P2)

플레이어는 'Space' 키를 눌러 타자기 효과를 즉시 완료하거나, 다음 대화로 넘어갈 수 있다.

**우선순위 이유**: 사용자가 이미 읽은 내용을 빠르게 넘기거나, 자신의 페이스에 맞춰 스토리를 진행할 수 있도록 하여 사용자 경험을 향상시킨다.

**독립 테스트**: 타자기 효과가 진행되는 도중 'Space' 키를 눌러 텍스트 전체가 즉시 표시되는지 확인한다. 텍스트가 모두 표시된 상태에서 'Space' 키를 눌러 다음 대화로 넘어가거나 대화가 종료되는지 확인한다.

**인수 시나리오**:

1. **Given** 텍스트가 타자기 효과로 출력되고 있을 때, **When** 플레이어가 'Space' 키를 누르면, **Then** 현재 대화의 모든 텍스트가 즉시 화면에 표시된다.
2. **Given** 현재 대화의 텍스트가 모두 표시되었을 때, **When** 플레이어가 'Space' 키를 누르면, **Then** 다음 대화 내용이 출력되거나, 마지막 대화일 경우 대화가 종료되면 게임 시간이 다시 흐른다.

---

### 사용자 스토리 3 - 외부 파일에서 대화 데이터 로드 (우선순위: P3)

대화 내용은 외부 JSON 파일에 정의된 순서대로 로드되어 게임에 표시된다.

**우선순위 이유**: 개발자가 코드를 직접 수정하지 않고도 대화 내용을 쉽게 추가하거나 수정할 수 있게 하여, 콘텐츠 제작 및 유지보수 효율성을 높인다.

**독립 테스트**: 특정 형식의 JSON 파일을 생성하고, 게임을 실행하여 해당 파일에 정의된 대화가 정확한 순서와 내용으로 출력되는지 확인한다.

**인수 시나리오**:

1. **Given** 특정 구조를 가진 대화 데이터 JSON 파일이 존재할 때, **When** 특정 NPC와의 대화가 시작되면, **Then** 시스템은 해당 JSON 파일을 읽어들여 대화 내용을 준비한다.
2. **Given** 대화 데이터가 로드되었을 때, **When** 대화가 진행되면, **Then** JSON 파일에 명시된 순서대로 대화가 화면에 출력된다.

---

### 예외 케이스

- 긴 대화 내용은 대화창의 너비에 맞춰 자동으로 줄바꿈 처리된다.
- JSON 파일 로드에 실패할 경우(파일이 없거나 형식 오류), 대화 기능은 비활성화되고 개발자를 위해 콘솔에 에러 로그가 기록된다.
- 대화 중 씬 전환 등으로 `DialogueManager`가 파괴될 경우, `OnDestroy()` 생명주기 메소드에서 `Time.timeScale`이 정상 값으로 복원된다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 화면 하단 중앙에 고정된 크기의 대화창 UI를 표시해야 한다.
- **FR-002**: 시스템은 대화 텍스트를 타자기 효과(Typewriter Effect)로 점진적으로 출력해야 한다.
- **FR-003**: 시스템은 대화가 활성화되면 게임 시간(Time.timeScale)을 0으로 설정하여 게임을 일시 정지시켜야 한다.
- **FR-004**: 시스템은 대화가 종료되면 게임 시간(Time.timeScale)을 원래 값으로 복원해야 한다.
- **FR-005**: 플레이어가 'Space' 키를 누르면, 진행 중인 타자기 효과를 건너뛰고 해당 대화의 전체 텍스트를 즉시 표시해야 한다.
- **FR-006**: 텍스트가 모두 표시된 상태에서 플레이어가 'Space' 키를 누르면, 시스템은 다음 대화로 넘어가야 한다.
- **FR-007**: 시스템은 외부 JSON 파일로부터 대화 데이터를 로드하여 순서대로 표시할 수 있어야 한다.
- **FR-008**: 시스템은 JSON 파일 로드 실패 시 대화 기능을 비활성화하고 콘솔에 에러를 기록해야 한다.
- **FR-009**: 시스템은 대화 내용이 대화창의 너비를 초과할 경우 자동으로 줄바꿈 처리해야 한다.
- **FR-010**: 시스템은 대화가 활성화된 동안 'Space' 키를 제외한 모든 게임 플레이 관련 입력을 무시해야 한다.
- **FR-011**: 시스템은 대화창에 현재 대화의 화자 이름을 표시해야 한다.
- **FR-012**: 시스템은 승객(NPC)이 데스크에 도착하는 이벤트 발생 시 자동으로 대화를 시작해야 한다.
- **FR-013**: 시스템은 대화 컴포넌트가 비활성화되거나 파괴될 때(예: 씬 전환), `Time.timeScale`을 정상 값으로 복원해야 한다.

### 주요 엔티티 *(데이터 관련 기능일 경우 포함)*

- **Dialogue (대화)**: 대화의 한 단위를 나타낸다. 출력할 텍스트(string)와 화자 이름(string)을 포함한다. (예: 초상화 이미지 경로 등 추가 정보 포함 가능)
- **DialogueSequence (대화 시퀀스)**: 하나의 완전한 대화 흐름을 나타낸다. 순서가 지정된 Dialogue 객체들의 리스트로 구성된다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 승객이 데스크에 도착하는 이벤트 발생 시 0.2초 이내에 대화창이 화면에 정상적으로 표시된다.
- **SC-002**: 타자기 효과 진행 중 'Space' 키 입력 시, 0.1초 이내에 전체 문장이 즉시 표시된다.
- **SC-003**: 대화가 진행되는 동안 게임 내 모든 움직이는 객체(애니메이션, 물리 효과 등)는 완전히 정지 상태를 유지한다.
- **SC-004**: 지정된 JSON 형식의 대화 파일을 시스템이 100% 정확하게 파싱하여 오류 없이 출력한다.
- **SC-005**: 마지막 대화에서 'Space' 키 입력 시 0.2초 이내에 대화창이 닫히고 게임 플레이가 즉시 재개된다.
